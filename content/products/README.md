# JHALAR Product Content

Products are managed in Pages CMS. Each published product is stored as a Markdown file in this folder.

## Product fields

```yaml
---
name: Premium Pom Pom Hanging
category: Pom Pom Hangings
tags:
  - wedding
  - festive
description_short: Handcrafted premium wool pom pom hangings for event installations and bulk supply.
description_full: Detailed product information goes here.
image_main: /static/images/products/premium-pom-pom.jpg
images_gallery: []
moq: 50
price: 450
specs:
  material: Premium wool
  size: 6 ft
  colours: Red, Gold, Multi-colour
featured: true
status: published
seo_title: Premium Pom Pom Hanging | JHALAR
seo_description: Handcrafted pom pom hangings for bulk event and wholesale requirements.
created_at: 2026-09-01
---
```

Only products with `status: published` appear on the public website.
